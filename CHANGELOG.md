# Changelog

## [0.1.0] - 2026-11-18

### Added

- Multi-connection segmented downloads.
- Persistent resume across restarts.
- Automatic reconnect on stalled connections.
- Pause and resume controls.
- Open file and open folder actions.
- Chrome extension bridge on `127.0.0.1:8765`.
- English-first interface with 11 languages.
- Settings, About and theme selection.
